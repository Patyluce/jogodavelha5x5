# 🎮 Jogo da Velha 5x5

Um jogo da velha com tabuleiro **5x5**, criado para praticar lógica de programação com **JavaScript** e construção de layouts com **Flexbox**.

## 🚀 Acesse o jogo

👉 **[Clique aqui para jogar](https://jogodavelha5x5.vercel.app/)**

## 🛠️ Tecnologias utilizadas

- **HTML5** - Estrutura da página
- **CSS3 + Flexbox** - Estilização e layout do tabuleiro
- **JavaScript** - Lógica do jogo, verificação de vitória e alternância de jogadores

## 🎯 O que foi praticado neste projeto

- Lógica de verificação de vitória em linhas, colunas e diagonais
- Manipulação do DOM
- Controle de turnos entre jogadores (X e O)
- Layout responsivo com Flexbox
